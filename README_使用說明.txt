華泰文化 × BenQ InstaShow 校園無線分享提案
網頁壓縮包，華泰文化 Logo 更新版

開啟方式
將 ZIP 檔完整解壓縮，保留檔案與 assets 資料夾的相對位置。
在電腦上使用瀏覽器開啟 index.html。
網頁程式與圖片已包含在壓縮包內，官方資料連結需連線開啟。

檔案說明
index.html：網頁內容。
style.css：桌面與手機版樣式。
app.js：情境切換、連接示範與機型比較等互動功能。
assets：產品圖片、華泰文化原始 Logo、圖示與字型。
.nojekyll：供 GitHub Pages 發布靜態檔案使用。

部署至 GitHub Pages
將解壓縮後的內容上傳至儲存庫的發布來源目錄。
讓 index.html 與 assets 資料夾位於同一層，再於儲存庫的 Settings／Pages 設定發布來源。

內容來源
本包依 InstaShow 已發布的 Logo 更新版製作。
華泰文化 Logo 沿用提供的原圖，產品與情境圖片沿用原始簡報素材。
產品規格與價格的資料日期及官方連結，保留於網頁中的說明。
